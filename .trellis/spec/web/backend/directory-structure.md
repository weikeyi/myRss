# Directory Structure

## Overview

This package does not currently own backend code. If backend helpers are added later, keep them thin and web-specific only.

## Module organization

- Do not add database or server feature logic here.
- Keep any future helpers local to the web app boundary.

## Naming conventions

- Use explicit, web-oriented names if backend helpers ever appear.
